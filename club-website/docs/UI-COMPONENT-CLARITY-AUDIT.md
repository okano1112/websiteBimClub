# ตรวจความชัดเจนและที่มาขององค์ประกอบ UI

วันที่ 18 กันยายน 2026 — ตรวจ source หน้า public, navigation/footer และหน้าจัดการที่เกี่ยวข้อง; ไม่ได้ตรวจข้อมูลส่วนตัวในฐานข้อมูลหรือรับรองข้อมูลประวัติชมรมจากหลักฐานภายนอก

## สิ่งที่แก้แล้ว

About timeline (`public/page/about.html`, `public/css/about.css`): เปลี่ยนกล่องเงา/ป้ายวันที่เป็นรายการประวัติเรียงแนวเดียว วันที่แยกคอลัมน์บน desktop และวางเหนือเนื้อหาบน mobile ใช้เส้นบางและตัวอักษรแทนกล่องตกแต่ง ย่อข้อความโดยไม่เพิ่มเหตุการณ์หรือวันที่ใหม่ ตัดคำกล่าวเชิงโฆษณาและจำนวนผู้ร่วมงานที่ไม่มีที่มาในส่วน timeline ออก เพิ่มลิงก์ไปกิจกรรม ใช้ ordered list และ time สำหรับเดือนที่ระบุแน่นอน ไม่ซ่อนข้อความรอ scroll animation

ยังเก็บวันที่ที่มีอยู่เดิมไว้เพื่อไม่สร้างข้อเท็จจริงใหม่ การปรับดีไซน์ไม่ได้ยืนยันว่าประวัตินั้นถูกต้อง

รายการอื่นเป็นผลการตรวจและข้อเสนอ ยังไม่ได้เปลี่ยน data source, permissions, API หรือเนื้อหาข้อเท็จจริงของหน้าเหล่านั้น การตัดสินใจเรื่องประวัติ/สถิติต้องมีผู้รับผิดชอบข้อมูลยืนยัน

## เกณฑ์ใช้กับ component ต่อไป

แต่ละส่วนควรตอบได้ว่า “แสดงอะไร”, “ข้อมูลมาจากไหน”, “ผู้ใช้ทำอะไรต่อได้” และ “เมื่อไม่มีข้อมูลจะแสดงอย่างไร” แยกข้อความตัวอย่างออกจากข้อมูลใช้งานจริง ห้ามใช้สถิติที่ไม่มีนิยามหรือปุ่มที่ทำเพียงแสดงข้อความสำเร็จแทนการทำงานจริง

## การตรวจ timeline

Chromium บน Docker local: 6 เหตุการณ์, ความกว้างหน้าไม่ล้นที่ 390/768/1024/1440px, ไม่มี page errors, ข้อความแสดงได้เมื่อ JavaScript ปิด; เปิดโหมด reduced motion แล้วไม่มี motion dependency ของ timeline การทดสอบใช้ empty fixture สำหรับ `/api/team` จึงไม่ตรวจหรือจับภาพข้อมูลสมาชิกจริง

ยังไม่ได้ทดสอบ Safari/Firefox หรือทำ accessibility audit เต็มรูปแบบ
